## About the project

InsightForm is a focused survey platform concept built around a calm, accessible, and
responsive user experience. It provides a strong foundation for teams that need to ask
better questions and make feedback easier to act on.

The current interface is built as a Vue 3 single-page application. The project is
structured to grow into a complete survey workflow with authentication, persistence,
response analytics, and integrations.

## Highlights

- Clear workspace for managing active surveys
- Responsive interface that works across desktop and mobile layouts
- Reusable Vue components with a lightweight design system
- Vite-powered development workflow with fast feedback
- Ready for API, authentication, and analytics integrations

## Tech stack

- **Vue 3** with `<script setup>`
- **Vite** for development and production builds
- **JavaScript (ES modules)**
- **CSS** with responsive layout and design tokens

## Getting started

### Prerequisites

- Node.js 16 or newer
- npm 8 or newer

### Installation

```bash
git clone https://github.com/PVegananda/insightform.git
cd insightform
npm install
```

### Development

```bash
npm run dev
```

Open the local URL shown in the terminal to view the application.

### Production build

```bash
npm run build
npm run preview
```
